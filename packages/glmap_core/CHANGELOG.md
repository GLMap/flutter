## 0.1.0-beta.1

- Pin the released native GLMap Core 2.2.0 artifacts on Android and iOS.
  Initialize Core before calling any native API, including headless services.

- Add process-wide SDK initialization and bundled dataset registration.
- Support regional and area downloads, cancellation and progress events.
- Provide shared coordinates, bounds, places and cancellable request types.
- Operate without the map renderer, Search or Route.
